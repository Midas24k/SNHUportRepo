# SNHUportRepo


This repository serves as a collection of projects, assignments, and other work completed throughout my Computer Science program at Southern New Hampshire University.

The purpose of this repository is to document my progress as a developer and demonstrate the skills I have developed across different areas of computer science. Each course folder contains selected projects or portfolio artifacts that represent the concepts, tools, and techniques covered in that class.

## Repository Purpose

This portfolio is used to:

* Organize completed coursework by course
* Preserve major projects and portfolio submissions
* Demonstrate growth in programming and software development
* Showcase experience with system analysis, software design, databases, algorithms, and application development
* Provide examples of technical documentation, diagrams, source code, and project planning
* Maintain a long-term record of work that can be referenced by instructors, employers, and future projects

## Repository Structure

Projects are organized into folders based on the course in which they were completed.

```text
Computer-Science-Portfolio/
│
├── CS-XXX-Course-Name/
│   ├── Project-One/
│   ├── Project-Two/
│   └── README.md
│
├── CS-XXX-Course-Name/
│   └── ...
│
└── README.md
```

Individual course folders may contain source code, project documentation, UML diagrams, reports, presentations, technical requirements, or other supporting materials depending on the course.
